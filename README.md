# HostMe Frontend

Web frontend for **HostMe**, an event ticketing platform: buyers browse events
and buy tickets (free or via M-Pesa) without an account; organizers manage
events and track sales.

This repository has no code yet. The full specification (pages, routes, API
contract, purchase flow, data types, testing and deployment) is in
**[FRONTEND_SPEC.md](FRONTEND_SPEC.md)**.

- Backend API: [serenade18/hostmeBackend](https://github.com/serenade18/hostmeBackend)
- Recommended stack: Vue 3 + TypeScript + Vite, Pinia, Vue Router, Tailwind CSS
- Dev server: `http://localhost:8080` (matches the backend's default `SITE_URL` and CORS settings)
